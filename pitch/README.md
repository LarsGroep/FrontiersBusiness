# Pitch: methods clips

Six 1080p clips (2:00 in total) for the methods part of the final pitch, in the style of the promo video.
`python methods.py clip <0-5> out.mp4` renders one clip; `lib.py` holds the shared drawing code from the promo.
`data.json` (not committed: built from coords.json, web/graph/*.json, one CODE-15% ECG and the Kaggle test predictions) feeds the map, symptom matches, tree path, ECG and survival curves.
